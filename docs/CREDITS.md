# Credits

No third-party art, audio, or font assets are included in the project. The
AK-47/arms view model, silhouette and bullseye targets are original low-poly
assets generated by `tools/generate_fps_assets.py`; their small PBR textures are
embedded in the GLB files under `assets/models/`. The arena uses project-made
geometry, and the interface uses Godot UI controls.

If third-party assets are added later, list each asset's name, creator, source,
and license here before including it in a build.
